    Contact

    Pin one of this actor's hands or feet to a joint of another actor at the current frame — a grab, a block, a throw. The pin becomes a target for the next generation (or Apply it in the Handles bar).

    React

    Place this actor against another actor at one of its markers, pin the pose it should be in at that moment, and write what it does. Generate makes the clip and it takes this actor's slot.

    Mix takes

    Tick a range from each take; the ranges stack as keeps for the next generation (full body, one key every 6 frames). The clip on the stage supplies the prompt and settings.

    Understudy

    Understudy is an animation tool. Describe a motion, keep the take you like, send it to the game.

    Built on NVIDIA Kimodo (motion models under the NVIDIA Open Model License) and the kimodo.cpp port by LocalAI with constraints by Digital Contraption Labs (Apache-2.0). Text encoder: Meta Llama 3 (Community License). Pose from the reference: Google MediaPipe (Apache-2.0), run in the page.

    The 60-second path

    1. Generate: describe the motion ("A person …"), set Takes, press Generate. The cleanest take is selected.
    2. Judge: the badges on the clip say foot slide, floor, jitter, hand in face, floaty jump — or clean.
    3. Fix: Handles (H) to move a hand, foot, hip, elbow or the look; Apply to clip, or Regenerate around it. Keep (K) to keep a range and regenerate the rest.
    4. Hands: set hand shapes from the Handles bar; they go to Unreal as curves.
    5. Scene: Actors tab → add actors, React…, "Actor 2 dodges Actor 1".
    6. Ship: Export → Send to Unreal (or GLB / BVH / video).

    Shortcuts: Space play/pause · ← → step (Shift: 10) · Home/End first/last frame · T trails · H handles · M marker · 1/3/7/5 views · P path · B body cycle · K keep · [ ] keep range · X skeleton through body · G generate · Ctrl+Z / Ctrl+Y undo / redo edits · Ctrl+A select all · Esc clear

    Prompt sheet

    One prompt per line. Add | 120 after a prompt for a frame count (default 150). Each line uses the current model, steps and Takes.

    Style set

    One action, generated for each gender × archetype. Prompts read “An elderly woman walks forward at an easy pace.”

    Locomotion set

    Each gait in each direction, with a root path so the motion really goes that way. Tagged for the coverage board (e.g. run_left).

    Needed animations

    One per line. A clip counts for a slot when it carries that tag; a favourite counts as approved.

    Pipeline settings

    Where Send to Unreal puts this project's clips. The editor must be closed while a job runs.
